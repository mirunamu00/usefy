Add the Latin layout catalog: **AZERTY** (French), **QWERTZ** (German), **Dvorak**, and **Colemak** built-in layouts (`azertyLayout`, `qwertzLayout`, `dvorakLayout`, `colemakLayout`), plus a shared `LATIN_VARIANTS` accent map. Each ships the same 26 letters, `?123` symbol layer, and long-press accent variants as `qwertyLayout` — only the key arrangement differs.
